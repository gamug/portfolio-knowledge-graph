# Proposed bilingual labels for the news rows (Work item 46, block D)

**Status: approved by Reviewer A on 2026-11-16, with the four changes in letter 26 applied.
Block D2 (full-article `body` rows) updates the class label and the `itemId`/`articleId`/
`sourceDomain` comments; Reviewer A approved the class name and the Spanish texts, and reviews the
English drafts afterwards.**
The TBox `rdfs:label`/`rdfs:comment` texts in `schema/tbox.ttl` are now frozen. `labels.ttl` is
not edited in this PR; the class and properties carry their bilingual texts directly.

This table follows `docs/labels-veto-review.md`: one row per term, with the Spanish and English
label and comment. It covers the new `:NewsItem` class and every new property (one per loaded
column, plus the optional Asset link and URL). The row's sentiment/category values are model
outputs, not verified facts; the text is the delivered fragment, never the full article.

## 1. New TBox class

| id | code / IRI | kind | ES label | EN label | ES comment | EN comment | Reviewer A decision | Notes |
|---|---|---|---|---|---|---|---|---|
| NEWS-CLS-01 | `NewsItem` | class | Noticia | News item | Una noticia (un fragmento o un artículo completo) asociada a una empresa: la fecha, el título, el texto exacto que entregó la instantánea de NLP (original o resumen), el dominio de la fuente, las probabilidades de sentimiento y categoría y las revisiones del modelo. El texto es el fragmento al que el modelo asignó la etiqueta, nunca el artículo completo (como máximo 2,000 caracteres); el sentimiento y la categoría son salidas del modelo, no hechos verificados. | One news item (a fragment or a full article) for one company: the date, title, the exact text the NLP snapshot delivered (original or summary), the source domain, the sentiment/category probabilities and the model revisions. The text is the fragment the model labelled, never the full article (at most 2,000 characters); sentiment and category are model outputs, not verified facts. | approved with change | subclass of `:EvidenceSource`; IRI from `(item_kind, item_id, ticker)` only |

## 3. Not proposed here

- No new `skos:Concept` label scheme: the class and property labels above are the TBox
  `rdfs:label`s, not presentation-vocabulary concepts. If Reviewer A wants a `NewsScheme` for
  reader-facing codes (`sub_news`, `original`, `summary`, the sentiment labels), that is a separate
  label-table pass and must not change `labels.ttl` before approval.
- The TTYG instructions are not edited in this PR.
