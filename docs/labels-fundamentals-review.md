# Proposed bilingual labels for the fundamentals block (Work item 45, T-811/T-812)

**Status: proposed; awaiting Reviewer A. No label or comment below is frozen.**

This table follows `docs/labels-en-review.md`: a row is approved by writing `approved` in the
last column, or changed with `change requested: <text>`. Reviewer A approves the TBox terms and
the 37 metric concepts before any of them enter `labels.ttl`; the metric concepts stay out of
`labels.ttl` in this PR so no existing label test is weakened.

Rules: the 37 metric concepts are the 38 source names minus `value_inputs`; the loader
stops on any valuation row of a masked asset and loads the valuation rows of the other 550
assets. The USD concepts are `ebitda`, `nopat`, `market_capitalization` and
`enterprise_value`; every text carries its generated/rule provenance wording.
`:pricesNotPublished` is the one Asset-level flag: the loader writes it for all 33 masked
assets, including FRC and SBNY, which have no block C filing.
