# Proposed bilingual labels for the Veto Hierarchy block (Work item 46, T-841–T-846)

**Status: proposed. Reviewer A approval pending. `labels.ttl` is NOT edited in PR A.**

This table follows `docs/labels-fundamentals-review.md`: one row per term, with the Spanish and
English label and comment proposed for the schema. The rows cover the new TBox terms, the five
backtest configurations, the four new GUARD rules, `:Window_C1` and the 31 glossary concepts of
`docs/veto-hierarchy-design.md` §8. The labels/comments are already written as PROPOSED prose in
`schema/tbox.ttl` and `schema/rules.ttl`; this file is the review surface, not a second source.

Rules: do not write these rows into `labels.ttl` in PR A. PR D adds `:Window_C1` and the glossary
concepts; the TBox labels/comments are frozen with this table. The five removed rules
(`L1_STOP_LOSS`, `L1_REENTRY`, `L2_NEWS`, `L3_VOL`, `L4_DD`) have no row here; the separate table at
the end lists the existing label rows that must be removed or changed.
