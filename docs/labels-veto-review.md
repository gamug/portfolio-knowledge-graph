# Proposed bilingual labels for the Veto Hierarchy block (Work item 46, T-841–T-846)

**Status: approved by Reviewer A on 2026-11-13. 130 rows approved, 25 approved with change, and the three new rows (VETO-PRP-103, VETO-PRP-104, VETO-PRP-105) approved.**

This table follows `docs/labels-fundamentals-review.md`: one row per term, with the Spanish and
English label and comment. Reviewer A's letter of 2026-11-13 is the authority; where this table and
the letter differ, the letter wins. The rows cover the new TBox terms, the five backtest
configurations, the four new GUARD rules, `:Window_C1`, the 31 glossary concepts of
`docs/veto-hierarchy-design.md` §8 and the new `:rejectedZoneNoSignal` row.

Rules: `:Window_C1`, the 31 glossary concepts and the corrected TBox texts are applied in PR D.
The five removed rules (`L1_STOP_LOSS`, `L1_REENTRY`, `L2_NEWS`, `L3_VOL`, `L4_DD`) have no row here;
the separate table at the end lists the existing label rows removed or changed.
